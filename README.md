This project, titled "Detection of Polycystic Ovarian Syndrome (PCOS) Using Machine Learning Algorithms," focuses on developing an intelligent, data-driven system for the early diagnosis of PCOS—a common hormonal disorder affecting women of reproductive age. The traditional methods of diagnosing PCOS often involve subjective evaluations, costly hormonal tests, and ultrasound imaging, which may not be accessible or efficient for all patients. This project aims to overcome those limitations by leveraging machine learning techniques on clinical and diagnostic data to predict the presence of PCOS with high accuracy and minimal reliance on invasive procedures.

The dataset used in this project was sourced from Kaggle and contains various clinical, biochemical, and lifestyle parameters such as hormone levels (FSH, LH, AMH, PRL, TSH), body metrics (BMI, blood pressure), and symptoms like acne, hair growth, skin darkening, and menstrual irregularities. After preprocessing and cleaning the data, relevant features were selected using statistical analysis and correlation matrices. Multiple machine learning models—including Logistic Regression, Random Forest, Decision Tree, K-Nearest Neighbors (KNN), and Support Vector Machine (SVM)—were implemented using Python and libraries like Scikit-learn, Pandas, and NumPy.

Each model was evaluated based on performance metrics such as accuracy, precision, recall, F1-score, and confusion matrix. Among all the models tested, Logistic Regression achieved the highest accuracy of 89%, followed by Random Forest and Decision Tree at 84%. The project also includes interactive visualizations and dashboards built using Plotly and Dash to help medical professionals and patients interpret predictions easily. The overall goal is to provide a reliable, interpretable, and cost-effective system that supports early detection and improves healthcare outcomes for women affected by PCOS.
